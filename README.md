# DataDash : Dashboard Météo Interactif

## Concept
Dashboard météo interactif affichant la météo en temps réel d'une ville, avec recherche dynamique, prévisions sur 5 jours et historique des recherches, le tout personnalisable via un système de palettes de couleurs.

## Stack technique
- HTML5 / CSS3 (Grid, Flexbox)
- JavaScript (Fetch API, async/await)
- API utilisée : [OpenWeatherMap API](https://openweathermap.org/api)
